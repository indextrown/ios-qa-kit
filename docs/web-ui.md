# 웹 UI (`qakit ui`)

명령어 대신 브라우저에서 결과를 보고, 시나리오를 골라 돌리고, 시뮬레이터 화면을 눌러 시나리오를 만듭니다. 내 Mac 안에서만 열리는 웹 화면이라 Node나 다른 설치가 필요 없습니다.

[← README](../README.md)

## 열기·닫기

```bash
qakit ui                  # 브라우저가 열립니다 (주소에 실행마다 바뀌는 토큰이 붙음)
qakit ui --no-open        # 주소만 출력
qakit ui --port 8765      # 포트 고정
qakit ui --device i       # 시나리오 실행을 실기기에서 (라이브 화면은 시뮬레이터만)
```

끝낼 때는 터미널에서 Ctrl+C를 누릅니다. UI에서 시작한 실행도 같이 멈춥니다.

- 터미널에 나온 주소를 엽니다. 주소는 열 때마다 바뀝니다.
- 다른 터미널을 계속 쓰려면 `qakit ui --no-open &`처럼 뒤로 돌리고, 출력된 주소를 엽니다.

## 메뉴

| 메뉴 | 할 수 있는 것 |
|---|---|
| **라이브 세션** | 시뮬레이터 화면을 보며 눌러 조작 → 시나리오로 저장, 만들어 둔 시나리오를 골라 돌리며 커서로 누르는 자리 보기 |
| **시나리오** | 골라서(태그로 한꺼번에) 실행, 실시간 로그, 최근 결과·불안정 표시 |
| **커버리지** | 앱 ID(자동 ID) 중 시나리오가 쓰는 비율을 화면별로. 펼치면 ID마다 쓰는 시나리오 또는 "시나리오 없음". 빈 화면의 **AI QA로**를 누르면 그 요소들을 확인하는 목표가 맡기기(또는 시나리오로) 입력칸에 채워진 채 AI 화면으로 넘어갑니다 |
| **편집** | 시나리오·공통 단계 YAML 편집 (고칠 때마다 검사) |
| **실행 기록** | 지난 실행의 통과·실패, 실패 원인·스크린샷·단계별 시간 |

| 메뉴 | 하는 일 |
|---|---|
| **라이브 세션** | 시뮬레이터 화면을 보면서 조작하고, 만들어 둔 시나리오를 골라 돌려 봅니다 (아래) |
| **시나리오** | 이름 앞부분(`alert`·`home`…)으로 묶어 보여 줍니다 (묶음 선택·접기). 체크하거나 태그로 한꺼번에 골라 실행하고, 줄마다 ▶(이것만 실행)·편집. **AI로 만들기**로 새 시나리오를 AI에게. 앱 재사용(`--reuse-app`), 실패하면 멈추는 방식, 사전 확인(precheck)을 고르고 로그를 실시간으로 봅니다. 시나리오마다 최근 10번 결과와 불안정 표시가 나옵니다 |
| **편집** | 시나리오·공통 단계 YAML을 고칩니다. 고칠 때마다 형식과 ID를 검사하고, 앱에 있는 ID를 찾아 넣을 수 있습니다. 밖에서 파일이 바뀌었으면 덮어쓰지 않습니다 |
| **실행 기록** | `results/`와 실행 기록을 통과·실패로 거르고 이름으로 찾습니다. 행을 누르면 실패 요약, 스크린샷, 실패 시점 화면 구조, 단계별 시간, 로그, 실패 영상을 봅니다 |

**화면 구성**: 왼쪽 메뉴는 QA(라이브 세션·AI) · 시나리오(시나리오·커버리지·편집) · 결과(실행 기록)로 묶여 있고 아이콘만 남기고 접을 수 있습니다. 위쪽 줄에 지금 위치(작업공간 › 메뉴 › 기기·실행·세션), 실행 중 표시, 테마(밝게·어둡게·시스템)가 있습니다. 라이브 세션은 가운데 기기, 왼쪽 세로 도구 막대(마우스를 올리면 이름), 오른쪽 상태 카드, 오른쪽 탭(조작 · 시나리오 실행 · 저장 — 시나리오가 돌면 그 탭으로, AI가 조작하면 탭 아래 AI 활동)입니다.

**라이브 세션으로 시나리오 만들기**

1. **앱 다시 켜기**를 누릅니다. 시나리오는 앱을 새로 켜고 시작하므로, 기록도 여기서부터 시작하는 게 좋습니다.
2. 화면에서 요소를 누르면 오른쪽 **고른 요소**에 ID(없으면 종류+라벨)가 나옵니다. **탭**, **나타날 때까지**, **보이는지 확인**, **위로·아래로 쓸기** 중 하나를 누릅니다. 단계는 `qakit do`로 바로 실행됩니다.
   - 입력칸(TextField 등)을 고르면 글자 입력칸이 나옵니다. 치고 **입력**을 누르면 `type: { into: …, text: … }` 단계로 실행·기록됩니다. 비밀번호 칸은 `{secret:키}`(secrets.txt)로 쓰세요 — 그대로 치면 기록에 남습니다.
   - 단계를 직접 쓰려면 **단계 직접 실행**에 `tap: HomeView.menuButton`처럼 입력합니다. 문법은 `.qa.yml`과 같습니다.
3. 통과한 단계는 **기록된 단계**에 쌓입니다. 단계마다 글자 고치기(두 번 클릭)·지우기·위/아래로 옮기기·이 단계만 실행(기록 안 함)이 됩니다. **앱 다시 켜기**(또는 AI의 `launch`)는 기록을 새로 시작하지만, 비우기 전 기록은 **이전 기록**(저장 탭 아래, 최근 10개)에 남아 **되살리기**로 돌려놓을 수 있습니다 (`qakit do restore`).
4. **시나리오로 저장**에서 이름·제목·태그(필요하면 시작 공통 단계)를 넣고 **초안 만들기** → **재생해서 확인**(앱을 새로 켜고 처음부터) → 통과하면 **scenarios/에 저장**합니다. 재생에 실패하면 저장되지 않습니다 — 초안을 그 자리에서 고쳐 다시 재생하면 됩니다 (재생 뒤 고치면 다시 재생해야 저장).

**툴바**

| 버튼 | 하는 일 |
|---|---|
| 일시정지·재생 | 화면 갱신을 멈추거나 다시 켭니다 |
| 실시간 · 스크린샷 | **실시간**(기본): 시뮬레이터가 그리는 화면을 바로 읽어 영상으로 보냅니다 (화면이 움직일 때 초당 약 20장, 시뮬레이터 창·권한 필요 없음, 옆에 지금 초당 장수). **스크린샷**: 정해진 간격(0.5~5초)으로 사진. 실시간이 안 되면 저절로 스크린샷으로 바뀝니다 |
| 사진 · 녹화 | **사진**: 지금 화면을 원래 해상도로 내려받습니다. **녹화**: 누르면 녹화, 다시 누르면 멈추고 `results/recordings/<시각>.mp4`에 남기며 내려받습니다 (버그 보고용) |
| 화면 구조 | 지금 화면의 요소를 다시 읽습니다. **실시간**에서는 화면이 크게 바뀌었다가 멈추면 저절로 다시 읽으므로(터미널 `qakit do`·손으로 만진 경우도) 대개 누를 일이 없습니다. 스크린샷 방식이거나 상자가 안 맞을 때만 |
| 요소 | 모든 요소 상자를 보이거나 숨깁니다. 파란 실선은 ID 있음, 노란 점선은 ID 없음(라벨로 찾음) |
| 커서 켬·끔 | 실행기가 누르는 자리로 화살표 커서가 움직이고 누른 곳에 퍼지는 원과 점을 남깁니다. 라이브 조작, 터미널의 `qakit do`, 시나리오 실행 모두 보입니다 (쓸기는 방향 표시). 마우스는 손가락 크기 원으로 바뀝니다 |
| 기록 모드 켬·끔 | 켜면 화면을 누르는 즉시 그 요소를 탭하고 단계로 기록합니다 (끄면 고르기만). 좌표가 아니라 ID·라벨로 실행·기록하고, 조작 탭에 기록 중인 단계가 보입니다. 직접 터치와 함께 켜면 끌기도 `swipe: { on: <목록·스크롤 영역>, dir }`로 기록합니다 |

**시나리오 골라 돌려 보기**: 오른쪽 맨 위 **시나리오 실행**에서 검색해 고르고 **실행**을 누르면, 왼쪽 화면으로 진행을 보고 결과와 로그를 바로 확인합니다. 실행하는 동안에는 조작이 잠깁니다.

**QA 브랜치 최신화**: 왼쪽 아래 브랜치 표시(`qa/workspace@…`)에 기준 브랜치 대비 **최신 / N 뒤처짐**이 나오고, 누르면 패널에서 가져올 커밋 목록을 보고 **최신화(병합)** 합니다 (`qakit worktree-update`와 같음 — 병합만, push 안 함, 다음 실행 때 앱 다시 빌드). 기준 브랜치(`develop`·`main`·`release/*` 등, 원격 브랜치 목록에서 고름)와 자동 방식(실행 전에 자동 / 알리기만 / 끔)도 여기서 바꿉니다 (`qakit.yml`의 `worktree:`만 고치고 주석은 그대로). 앱 소스에 커밋하지 않은 변경이 있거나 시나리오·AI가 도는 중이면 최신화하지 않습니다.

**알아 둘 것**

- `127.0.0.1`에만 열리고, 처음 연 주소의 토큰으로 로그인합니다. 주소를 다른 사람에게 보내도 그 Mac 밖에서는 열리지 않습니다.
- 라이브 화면과 조작은 지금 시뮬레이터에서만 됩니다.
- 실시간 화면은 Xcode의 비공개 부품(CoreSimulator)으로 시뮬레이터 화면 메모리를 읽습니다 (tapflow·idb와 같은 방식). Xcode가 바뀌어 안 되면 스크린샷으로 돌아가고 화면 아래에 이유가 나옵니다. 원리: [docs/live-screen.md](live-screen.md) 보는 브라우저가 없으면 30초 뒤 멈춥니다.
- 누르는 자리 표시는 시뮬레이터만 됩니다 (실행기가 `.qakit/taps.jsonl`에 남긴 자리를 읽음).

고른 요소의 **단계 대상** 옆 배지는 대상이 무엇에 기대는지(ID / ID + 줄 글자 / 라벨 / 포함 글자 / 순서)를 보여 줍니다. 순서 번호(`index`)는 화면이 조금만 바뀌어도 다른 요소를 고르므로 경고로 표시합니다.

AI에게 말로 시키는 곳은 **AI** 메뉴입니다 (대화·맡기기·시나리오로). 라이브 세션에는 AI가 조작하는 동안 활동만 보입니다. 자세히: [AI](ai.md)
